# AIROOM · 我们的 AI 工作室

AIROOM 是一个装在自己电脑上的“AI 工作室”。

你可以把 Claude、Codex、DeepSeek、Qwen、KIMI 等不同的 AI 编程助手请进同一个窗口，给每位起名字、配头像和性格，让它们像同事一样：

- 单独帮你干活；
- 一起聊天、开会；
- 各写一稿互相比较；
- 分工完成一个项目，最后由你验收。

每位成员背后都是一个真实的官方程序（例如 Claude Code、Codex CLI），用你自己的账号登录。AIROOM 负责把它们组织起来，并把它们说了什么、做了什么、改了哪些文件，都清楚地摆在你面前。

> 当前版本：**0.1**

[下载最新版本](https://github.com/tonyAmadeus/offAice/releases/latest) · [技术说明](docs/技术说明.md) · [用 AI 修改和部署 AIROOM](docs/AI协作开发指南.md)

- **免安装版**：下载 `AIROOM-0.1.0-Windows-x64-Green.zip`，**完整解压后双击 `AIROOM.exe`**；
- **安装版**：下载 `AIROOM-Setup-0.1.0.exe`，按向导安装，可选择安装目录，附带卸载程序。

支持 Windows 10 / 11 x64，无需安装 Node.js 或 npm。下载页同时提供 SHA-256 校验文件。

程序包不含账号、聊天记录或预装的成员程序。首次启动是空白工作台，没有人物卡或预配置连接。到“设置与连接 → 连接与版本”下载官方程序，或手动配置本机执行端，再登录并添加人物卡；下载和使用成员需要联网。某些成员程序另需 Node.js，按界面提示配置。

| 你想…… | 去哪里 |

## 第一次使用

### 1. 打开程序

双击桌面或开始菜单里的 **AIROOM** 图标。

使用绿色版时，双击解压文件夹里的 `AIROOM.exe`。

- 安装版默认位于 `%LOCALAPPDATA%\Programs\AIROOM`（安装时可更改），绿色版位于你选择的解压文件夹；
- 关掉窗口后，它会缩到右下角托盘里继续待命；
- 要彻底退出，请在托盘图标上右键选择退出。

### 2. 看一眼“开工前检查”

首次使用先到“设置与连接”添加执行端和人物卡。人物可以自定义，也可选择 Claudia、Gptia、DS 的形象模板；形象与执行端独立绑定，之后可以更换。更换执行端只影响新会话，已有会话保留原执行端和聊天记录。升级已有资料不会清空人物卡。

首页的“开工前检查”会列出每位成员的状态：

- **已就绪**：可以直接用；
- **需要登录**：点“去登录”，按官方程序的提示登录一次；
- **缺少程序**：到“设置与连接 → 连接与版本”里，从清单下载对应的程序。

### 3. 设置你自己

在“设置与连接 → 个人资料”里写上成员该怎么称呼你。

### 4. 认识你的团队

左侧“团队”栏列出所有成员。点一位成员会弹出人物卡，能看到 TA 的：

- 性格和当前状态；
- 连接情况、额度和长期记忆。

在“管理人物卡”里，可以改名字、头像、立绘、性格、默认模型和思考程度。

### 5. 选一个房间开始

下一节会告诉你怎么选。

## 成员工位：一对一干活

在左侧点成员名字旁边的“工位”图标，或在人物卡里点“去 TA 的工位聊天”。

**话题**

- 每次“开新话题”都会开一段独立的对话，旧话题会归档，随时能翻回去；
- 不起名字的话，AIROOM 会用你第一句话的前 20 个字自动命名；开头的 @ 点名会自动去掉。

**工作文件夹**

点“切换文件夹”可以选择成员在哪个文件夹干活：

- **个人文件夹**：成员的私人空间，改动直接保存；
- **其他文件夹**（比如你的项目）：成员先在一份**任务副本**里改，原文件夹不会被动到。

你确认没问题后，在“⋯”菜单里有三个选择：

| 选项 | 作用 |
| --- | --- |
| **应用到原文件夹** | 把改动写回原文件夹，写之前会检查冲突 |
| **撤销最近一轮** | 恢复到这一轮开始前的样子；已经写回的，原文件也一起恢复 |
| **丢弃工作副本** | 放弃这份副本的所有改动 |

**模型和思考程度**

- 输入框左下角可以给当前话题单独选模型和思考深度，例如 Opus、max；
- 成员回复旁边会显示这一轮**实际用的模型**。

**图片和文件**

- 点输入框的“+”，或者直接把文件拖进来，就能附上图片或文件，成员能看图回答，也能接着追问；
- 每次发送前都可以再加附件。

## 茶歇室：一起聊天、开会

茶歇室是大家的公共休息区。先在顶部“在场”栏点选谁在场，再用下面两种方式之一。

### 闲聊

成员自由接话，聊到自然告一段落就停下：

- 不限次数，你可以随时插话；
- 用 `@名字` 可以指定谁优先接话；
- 成员问你问题而你不想马上回答，也没关系：大家会继续聊，问题会留在在场栏，等你有空再答。

### 开会

每人按顺序回答一次，然后等你。

- **举手模式**：一轮结束后，想补充的成员会“举手”；
- 勾上“举手后由我点名”，就由你决定谁接着说；
- 讨论够了，点 **整理会议纪要**，选一位成员写出结论、分歧和下一步，会议结束。纪要只列本次参会的人。

### 其他

- **生成图片**：输入框旁的图片按钮，让使用 Codex 的成员画一张图。图下面有“修改这张图”，可以接着改。
- **话题菜单（⋯）**：
  - **压缩上下文**：话题太长时让成员写份摘要，之后从摘要继续，原消息保留；
  - **导出聊天室**：存成 Markdown 文件，图片和附件会写明文件名；
  - **清空当前话题**。
- **开新话题**：默认会把旧话题压缩成摘要带进新话题，成员不用从头了解。不想带，点“不再延续”。

## 项目会议室：分工做项目

### 开始

点首页的 **请大家一起来**，或者在左侧“项目”栏点 “+” 添加一个文件夹作为项目，再选好参加的成员（至少两位），就进入了这个项目的会议室。

### 一个项目的六步

页面上方的进度条会告诉你走到了哪一步：

1. **讨论**：在聊天里说清楚要做什么、有什么要求。成员可以查看项目文件核实现状，但不会改文件。
2. **定负责人**：点“选负责人，起草方案”，选一位成员当负责人。
3. **方案**：负责人写出方案，包括交付什么、怎样算完成、分几轮、每项任务给谁。你看过后点 **确认方案，开工**，不满意就点“要改一下”。
4. **执行**：成员按方案干活，每项任务都在**独立副本**里进行，你的原文件夹在验收前不会变。
5. **验收**：每轮做完，你查看成品和改动，选择 **通过** 或 **驳回**。
6. **完成**：通过后成品写回你的项目文件夹。想继续，点“开始新的一段工作”。

### 复核程度

开工前可以选成员之间互相检查的力度：

| 选项 | 怎么检查 | 适合 |
| --- | --- | --- |
| **深入复核** | 每项任务和每轮成果都有人检查 | 重要的活，调用次数多 |
| **标准复核** | 只检查每轮的汇总成果 | 大多数情况 |
| **快速推进** | 每轮由你决定要不要复核 | 简单的活，最省调用 |

不管选哪种，最后都由你验收。

### 工作中常用的操作

- **下一步按钮**：页面会提示你现在该做什么，比如“查看并确认方案”“查看成品并验收”。点一下就会跳到对应的卡片。
- **待你处理**：输入框上方的折叠区，放着等你确认的方案、决定和验收。内容多时在区内滚动，也可以收起；右侧按钮可以让它铺满聊天区，或在独立窗口里查看，处理方式不变。
- **成果文件**：每个文件右侧的文件夹按钮会在资源管理器中定位它。写回项目前定位的是 AIROOM 保存的本轮提交副本，只用来查看，请不要在里面修改。
- **@ 正在干活的成员**：输入框旁会出现“点名用途”，有三种选法：
  - **只是问问**：TA 只回答，不改任务；
  - **安排新任务**：追加一项任务，由负责人补全后你确认；
  - **补充到 TA 当前的任务**：把补充要求送到 TA 正在做的那项任务里。
- **暂停 / 继续**：右上角的“暂停”会让正在做的任务做完，然后不再派新任务；点“继续”接着派。
- **成员汇报**：进度条右边有每位成员的汇报页，可以看 TA 做了什么。在汇报页提问，成员只读回答，不会改文件。
- **看板**：右侧按“待开始 / 进行中 / 已完成”列出所有任务，“项目进度”能看历次工作。嫌聊天区太窄，点右上角 **收起看板**，需要时再展开。

## 圆桌：比稿、评审、选方案

适合“我想要几个版本，比一比”的场合，不需要建项目。

1. 点左侧 **圆桌 → 开新议题**，选类型：
   - **评审**：大家各自检查同一份材料，挑问题；
   - **比稿**：每人独立写一版同样的东西；
   - **方案比较**：每人提一个方案。
2. 写下材料或要求，也可以拖入文件，再选参加的成员和汇总成员。
3. **各自准备**：成员独立写，公开前互相看不到。
4. **公开**：可选“互评”，让大家只看别人的版本并提意见；汇总成员会整理出问题清单。
5. **审议讨论**：大家就这些意见讨论，每人说一次后等你。
6. 按“下一步：比较并选择候选”打开 **并排对比**，在想要的那份上点 **采用此候选**。
7. 点 **整理会议纪要**，然后点 **确认结论**。
8. 需要的话，点 **带回项目**，把结论作为材料送进某个项目会议室。

进度区会显示每人交了几份材料、一共几个问题，以及调用次数。

## 待你处理

左侧的 **待你处理** 会汇总所有需要你的事，比如：

- 成员在等你回答；
- 有操作等你确认；
- 有结果需要核对；
- 有成员需要登录；
- 有成品等你验收。

点其中一项，就会直接跳到对应的位置。

## 其他好用的功能

- **用量与额度**：团队栏顶部的图表按钮。能看各成员的额度和余额，点“刷新额度”可以重新查询。
- **自动功能与定时任务**：团队栏顶部的时钟按钮。
  - **成员闲聊**：你不在时，成员偶尔在茶歇室聊两句，有每日上限；
  - **定时任务**：在固定时间让某位成员发言，或者给你一个本地提醒；
  - 程序关着时错过的定时任务不会补发。
- **全部中止**：托盘菜单里可以一键停止所有成员的工作。
- **系统通知**：程序在后台时，成员完成任务或向你提问，会有系统通知或任务栏闪烁。

## 安全感从哪里来

- **你的文件先不动**：除了成员的个人文件夹，所有改文件的工作都在副本里进行。写回原文件夹之前，都要你确认或验收。
- **不会偷偷重发**：如果程序意外关闭、断网，或者不确定某次请求有没有送到，AIROOM 会标成“结果待核对”，等你看过再决定，绝不自动重发，避免重复花费额度。
- **随时能停**：输入框旁的“中止”、侧栏成员的“中止”、托盘的“全部中止”，都能马上叫停。
- **账号各管各的**：每个成员程序在 AIROOM 里有独立的登录目录，不会去读你其他软件里的登录信息；密钥由 Windows 加密保存。
- **调用看得见**：“累计尝试 / 已发出 / 已完成”分开显示，没发出去的、结果未知的单独列出。

## 资料与备份

- 所有资料都在你自己的电脑上：聊天记录、人物卡、图片、附件、工作副本，默认存放在 `C:\Users\你的用户名\.airoom\data`。
- **备份**：在“设置与连接 → 工作台 → 备份”里点 **立即备份资料**。
  - 备份保存在 `C:\Users\你的用户名\.airoom\backups`，只保留最新一份；新备份校验成功后，才会删除旧的那份；
  - 登录信息和密钥不进备份，换电脑恢复后需要重新登录；
  - 建议在大改动或升级前备份一次。
- **恢复**：在同一页面选一份备份，先“准备恢复”预览，确认后再恢复。恢复前会自动把当前资料再备份一次，失败会回退。

## 常见问题

**成员显示“需要登录”怎么办？**
在首页“开工前检查”或“设置与连接 → 连接与版本”里点“登录”，按官方程序的提示完成。

登录进行中可以取消。首次启动刚下载的成员程序会慢一些：授权页面 30 秒内还没出现时只会提示继续等待，不会中断登录；授权等待超过 5 分钟才会结束这次登录。登录程序没有报告完成时，AIROOM 会再检测一次连接，账号其实已经登录就直接显示登录成功。浏览器没有打开时，可点“打开官方授权页面”。需要切换账号时，先在连接设置中点“登出”，再重新登录；登出会保留聊天记录，也不会退出你在普通浏览器中的网站账号。

**成员回复显示“结果待核对”是什么意思？**
这一轮成员程序结束了，但 AIROOM 无法确认结果，例如没有返回任何内容，或者中途程序被关闭。AIROOM 不会自动重发。先看看已有内容，常见原因是登录过期或网络中断，可以到“设置与连接”检查这位成员，然后再重新发一句。

**怎么让成员停下来？**
点输入框旁的“中止”，或侧栏成员行的“中止”，或托盘的“全部中止”。已经说出的话和保存的文件版本都会保留。

**项目会议室的聊天区太小？**
- 点右侧看板的“收起看板”；
- 把“待你处理”区收起来；
- 窗口拉大、全屏也会有帮助。

**草稿会丢吗？**
不会。每个话题的草稿、附件和回复对象都会自动保存，切换房间、重启程序都还在。

**调用次数和我的账单对得上吗？**
AIROOM 的次数是它自己发出的请求数，不等于订阅账单。真实的额度和费用以各官方程序返回的数据为准。

**换了电脑或重装怎么办？**
- 在旧电脑上备份；
- 把 `.airoom\backups` 里的备份拷到新电脑；
- 用“准备恢复”还原；
- 然后重新登录各成员程序。

**如何卸载？**
安装版可在 Windows“设置 → 应用 → 已安装的应用”中卸载，或运行安装目录里的 `Uninstall AIROOM.exe`。绿色版从托盘彻底退出后，删除解压文件夹即可。两种方式都会保留 `%USERPROFILE%\.airoom` 中的个人资料；绿色版与安装版默认共用这份资料。

## 已知限制

- **ZCode（GLM）**：连接检查能通过，但真实对话还没有稳定完成，目前算“试用中”，不建议放进主要流程。
- **很早以前的 DeepSeek 旧话题**：可能接不上原来的会话。遇到时直接开新话题。
- **Codex 在多人房间里**：偶尔会初始化超时，那一次会被跳过，不会重复发送，其他成员照常继续。
- **KIMI 等成员登录过期**：可能只返回空内容，重新登录即可。
- **“修改这张图”和生成图片**：需要使用 Codex、并且允许联网的成员。

开发环境需要 Windows、Git，建议使用 Node.js 26（与本项目验证环境一致）：

```powershell
npm ci
npm run dev
```

本地开发也可以双击根目录的 `Start-AIROOM-Dev.cmd`：每次先构建最新代码再打开桌面程序，失败时保留错误提示。`Start-AIROOM.cmd` 优先启动已部署或已安装的版本（依次查找桌面的 `AIROOM` 文件夹、`%LOCALAPPDATA%\Programs\AIROOM`、`%USERPROFILE%\AIROOM`），都没有时转到开发入口。Windows 开发运行时会复制到 `%LOCALAPPDATA%\AIROOM\development-runtime`，避免项目目录的低完整性标签影响启动；不需要管理员权限。修改代码后重新运行开发入口即可。

其他验证命令：

```powershell
npm run build
npm start
npm run verify
```

`npm run verify` 依次运行类型检查、全部测试、界面冒烟、构建和桌面冒烟。测试都用临时的、未登录的目录，不会碰日常资料。

对外签名构建使用 `npm run package:signed`（安装器与便携 EXE）或 `npm run package:green:signed`（绿色 ZIP）。先按 electron-builder 的 Windows 签名配置提供受信任证书；签名入口在缺少证书或 Windows 校验不通过时失败。普通本地构建仍可运行，`build-manifest.json` 会记录实际签名状态。未签名包可能出现“Windows 已保护你的电脑／未知发布者”；新签名也需要积累 SmartScreen 信誉，不能保证首次下载无提示。参见 [Microsoft 的说明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)。
